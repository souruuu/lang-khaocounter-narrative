## ขอบเขตที่ต้องไม่สับสน

- **Demo Day 1–3:** มีเด็ก 4 คน มะนาว ส้ม นัท กันต์ และเหตุการณ์หลัก 9 ฉาก
- **แผนเกมเต็ม Day 4–7:** บาสปรากฏ Day 4, งานซ่อมรถของเล่น Day 5, กล่องดนตรี Day 7; เรื่องเหล่านี้ยังไม่อยู่ใน Demo Day 1–3
- ใน Narrative Map รุ่นเดิมอาจมีเหตุการณ์/ลำดับที่ต่างจาก Demo ปัจจุบัน: **ให้ยึดคำตัดสินล่าสุดของเจ้าของเกมและเอกสาร Editorial ที่อนุมัติสำหรับ Demo** แทนข้อเสนอเก่าที่ขัดกัน
- ชื่อไฟล์บางชิ้นยังมีคำว่า `Proposal` เพราะเป็นชื่อที่ใช้ระหว่างกระบวนการเขียนเดิม ไม่ใช่การอนุมัติข้อเสนอใหม่อัตโนมัติ
- ชุดนี้ **รวม `.ink` ที่เกมใช้จริง 4 ไฟล์** เพื่อใช้อ่านบทเท่านั้น โดย `.ink` เป็น Narrative Script ที่มีคำสั่งแตกแขนงและรหัสประกอบ ไม่ใช่ TypeScript/React Source Code; ชุดนี้ไม่รวม Source Code ตัวแอป, ไฟล์ทดสอบ, Asset หรือระบบหลังบ้าน
- ถ้าจะปรับบทหรือ Choices ให้ทำเป็นข้อเสนอใหม่แยกจากไฟล์ `.ink` ต้นฉบับที่อนุมัติแล้ว เพื่อให้เจ้าของเกมตรวจผลกระทบต่อรหัส Choice/Line และระบบจดจำก่อนนำไปใช้
- นำเสนอ Narrative Treatment และ Choices ที่เสนอแก้ใหม่ได้เต็มที่ แต่ยังไม่ถือว่าบทใหม่ได้รับอนุมัติให้นำเข้าเกม
